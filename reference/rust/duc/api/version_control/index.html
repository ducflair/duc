Module version_control 

Source
Expand description

Version-graph restore & mutation API over a DucConnection.

Provides high-level operations for:

  • Restoring document state at any version (checkpoint or delta replay)
  • Creating new checkpoints and deltas
  • Listing version history

All operations work directly against the embedded SQLite schema (version_control.sql) and produce/consume the canonical Rust types from crate::types.
