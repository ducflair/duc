pub fn parse_duc_bytes(buf: &[u8]) -> ParseResult<ExportedDataState>
Expand description

Parse a .duc file (gzip-compressed SQLite bytes) into an ExportedDataState.

This is the byte-buffer equivalent of crate::session::DucSession::open_path. On non-WASM targets it writes the decompressed SQLite to a temp file. On WASM targets it uses an in-memory database.
