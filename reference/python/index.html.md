# ducpy

**Builders API (High-level)**
: The easy way to build, manage `.duc` files.
  Construct elements, apply styles, manage layers, build blocks,
  and handle document state with the
  [builders](autoapi/ducpy/builders/index.html.md) module.

**SQL Builder (Low-level)**
: A `.duc` file is a gzip-compressed SQLite database. Use the
  [sql_builder](autoapi/ducpy/builders/sql_builder/index.html.md)
  for direct schema access, bulk queries, and low-level manipulation.

**Search**
: Query/search elements and files programmatically via the
  [search](autoapi/ducpy/search/index.html.md) API.

**File I/O**
: Read and write `.duc` files using the
  [parse](autoapi/ducpy/parse/index.html.md) and
  [serialize](autoapi/ducpy/serialize/index.html.md) modules.
